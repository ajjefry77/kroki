## معرفی پروژه

**سامانه کروکی** یک برنامه وب فارسی (RTL) برای تولید حرفه‌ای نقشه‌های کروکی املاک است. این سامانه به کارشناسان نقشه‌بردار، مهندسان عمران و مشاوران املاک امکان می‌دهد تا با استفاده از نقشه تعاملی، اطلاعات ملک را وارد کرده و خروجی‌های استاندارد و چاپ‌پذیر در قالب‌های مختلف سازمانی تولید کنند.

---

## قابلیت‌ها

### ترسیم نقشه تعاملی
- ترسیم چندضلعی و خطوط روی نقشه Mapbox
- جستجوی مکان با آدرس فارسی
- حذف و ویرایش ترسیم‌ها
- پشتیبانی از چند ترسیم همزمان

### محاسبات هندسی و مختصاتی
- تبدیل خودکار مختصات WGS84 به UTM
- محاسبه مساحت اراضی چندضلعی
- محاسبه مرکز هندسی هر ترسیم
- آدرس‌یابی معکوس (Reverse Geocoding) با سرویس map.ir
- تعیین خودکار شمال غربی‌ترین نقطه برای برچسب‌گذاری

### قالب‌های خروجی
- **فنی مهندسی**: استاندارد نظام مهندسی با جدول مختصات UTM
- **ثبتی**: قالب رسمی سازمان ثبت اسناد و املاک
- **شهرداری (دولاین)**: نقشه یوتی‌ام دولاین شهرداری
- **بنیاد مسکن**: قالب مصوب بنیاد مسکن انقلاب اسلامی
- **رنگی ارائه**: نقشه رنگی برای ارائه و گزارش
- **دستی / بیمه**: کروکی توصیفی ساده برای گزارش حادثه و بیمه

### خروجی‌ها
- **چاپ PDF**: خروجی A4 عمودی و افقی با CSS چاپ اختصاصی
- **دانلود تصویر PNG**: خروجی با کیفیت بالا
- **خروجی KML**: برای استفاده در Google Earth
- **خروجی DXF**: برای استفاده در نرم‌افزارهای CAD

### مدیریت کاربران
- ثبت‌نام و ورود با نام کاربری و رمز عبور
- پنل مدیریت ادمین (مدیریت کاربران، آمار، تراکنش‌ها)
- پنل کاربری (مشاهده کروکی‌ها، تراکنش‌ها، شارژ کیف پول)
- سیستم نقش‌ها (کاربر عادی، ادمین، نماینده)
- سیستم کیف پول و شارژ دستی
- سیستم کدهای معرف و پاداش

### سیستم نمایندگی
- درخواست نمایندگی شهری
- مدیریت زیرمجموعه‌ها
- پیگیری تراکنش‌های نمایندگان

### سایر امکانات
- طراح قالب شخصی (Template Designer)
- سیستم لاگ و دیباگ
- تاریخ شمسی (جلالی)
- رابط کاربری فارسی کاملاً راست‌چین (RTL)
- انیمیشن‌های روان بین مراحل
- مدیریت وضعیت با URL Hash
- بهینه‌سازی بارگذاری با Async Components

## پیش‌نیازها

- **Node.js** نسخه ۱۸ یا بالاتر
- **npm** نسخه ۹ یا بالاتر
- **بک‌اند** در حال اجرا (`https://mapiq.ir:3003` یا آدرس سفارشی)
- **توکن Mapbox** عمومی (از [mapbox.com](https://www.mapbox.com/) دریافت شود)

---

## راه‌اندازی

### ۱. کلون کردن پروژه

```bash
git clone <آدرس ریپوزیتوری>
cd kroki/frontend
```

### ۲. نصب وابستگی‌ها

```bash
npm install
```

### ۳. پیکربندی متغیرهای محیطی

```bash
cp .env.example .env
```

سپس مقادیر `.env` را ویرایش کنید ( phần [متغیرهای محیطی](#متغیرهای-محیطی) را ببینید).

### ۴. اجرای برنامه در حالت توسعه

```bash
npm run dev
```

برنامه روی `http://localhost:5174` اجرا خواهد شد.

### ۵. ساخت نسخه Production

```bash
npm run build
```

فایل‌های خروجی در پوشه `dist/` ذخیره می‌شوند.

### ۶. پیش‌نمایش نسخه Production

```bash
npm run preview
```

## متغیرهای محیطی

فایل `.env` در ریشه `frontend/`:

| متغیر | توضیح | مقدار پیش‌فرض |
|--------|-------|--------------|
| `VITE_SERVER` | آدرس بک‌اند (برای لاگین و API) | `https://mapiq.ir:3003` |
| `VITE_MAPBOX_TOKEN` | توکن عمومی Mapbox (سمت کلاینت) | — |
| `VITE_MAP_IR_KEY` | کلید عمومی map.ir برای آدرس‌یابی معکوس (اختیاری) | — |

> **نکته امنیتی**: توکن Mapbox و کلید map.ir توکن‌های عمومی (public) هستند و سمت کلاینت استفاده می‌شوند. هرگز کلید خصوصی (secret) در فایل `.env` قرار ندهید.

## فرآیند کاری

سامانه کروکی از یک ویزارد ۵ مرحله‌ای استفاده می‌کند:

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  ترسیم   │───▶│ اطلاعات  │───▶│پیش‌نمایش │───▶│ پرداخت   │───▶│ دانلود   │
│  نقشه   │    │  و قالب  │    │          │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

1. **ترسیم نقشه**: کاربر اشکال هندسی (پلی‌گان/خط) را روی نقشه تعاملی ترسیم می‌کند
2. **اطلاعات و قالب**: اطلاعات ملک (نام متقاضی، آدرس، پلاک ثبتی و ...) و قالب خروجی انتخاب می‌شود
3. **پیش‌نمایش**: کروکی تولیدشده پیش از چاپ نمایش داده می‌شود
4. **پرداخت**: هزینه کروکی از کیف پول کسر می‌شود
5. **دانلود**: خروجی PDF، PNG، KML یا DXF دانلود می‌شود

## API بک‌اند

بک‌اند این پروژه به صورت جداگانه در `https://mapiq.ir:3003` اجرا می‌شود. اندپوینت‌های اصلی:

### احراز هویت
| متد | مسیر | توضیح |
|-----|------|-------|
| `POST` | `/api/auth/register` | ثبت‌نام کاربر جدید |
| `POST` | `/api/auth/login` | ورود به سامانه |
| `GET` | `/api/auth/me` | دریافت اطلاعات کاربر جاری |
| `PATCH` | `/api/auth/me` | ویرایش اطلاعات کاربر |

## قانونی و حقوقی

### مالکیت معنوی

این نرم‌افزار و تمام حقوق مادی و معنوی آن از جمله اما نه محدود به:

- کد منبع (Source Code)
- رابط کاربری (UI/UX)
- قالب‌های خروجی
- طراحی و لوگو
- مستندات و محتوا

**متعلق به شرکت ساج گستر کاسپین می‌باشد.**

### شرایط استفاده

1. **کپی‌برداری**: هرگونه کپی‌برداری از کد منبع یا بخش‌هایی از آن بدون اجازه کتبی ممنوع است.
2. **تغییرات**: اعمال تغییرات در نرم‌افزار بدون مجوز رسمی شرکت مجاز نیست.
3. **انتشار**: انتشار عمومی یا خصوصی نرم‌افزار بدون تأیید شرکت غیرقانونی است.
4. **استفاده تجاری**: بهره‌برداری تجاری از نرم‌افزار مستلزم عقد قرارداد با شرکت ساج گستر کاسپین است.
5. **.mediasuite**: هرگونه مالکیت فکری و معنوی مرتبط با برند، نام تجاری و هویت بصری متعلق به شرکت می‌باشد.

### مسئولیت‌ها

- کاربر مسئول حفاظت از اطلاعات حساب کاربری خود است.
- شرکت هیچ مسئولیتی در قبال استفاده غیرمجاز از حساب کاربری کاربران ندارد.
- اطلاعات شخصی کاربران مطابق با قوانین جمهوری اسلامی ایران حفاظت می‌شود.
